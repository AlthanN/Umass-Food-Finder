# Archived prototypes

These files are preserved as historical hackathon experiments. They are not
imported by or required for the Flask website. The maintained scraper lives in
`food_finder/scraper.py`.

The Elasticsearch examples are intentionally non-functional: credentials and
deployment details were removed. Because a real credential was previously
committed, it must be revoked or rotated; deleting it from the current version
does not erase it from Git history.
